This repo contains two game prototypes built with Claude Code:

- **`mythrunner/`**: *Mythrunner*, an iOS (Swift + SpriteKit) Alto-style runner through 30 realms of world mythology, with a spirit-guide companion that teaches history as you play. Start with [`mythrunner/README.md`](mythrunner/README.md).
- **Root (`main.py` etc.)**: *Echoes of the Fractured Age*, the original top-down Python/pygame prototype (`pip install -r requirements.txt && python main.py`).
